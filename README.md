# 🎙️ Бесплатная русская озвучка для Anywhere RPG

Честно признаемся: это «дешманская» (в хорошем смысле) альтернатива официальной платной озвучке, созданная специально для русскоязычных игроков в обход региональных ограничений и подписок Sapphire/Obsidian.

**🎭 Какие голоса вас ждут:**
* 👩 **Женские персонажи:** Слегка безэмоциональный, но очень четкий голос Google Ассистента (gTTS).
* 👨 **Мужские персонажи:** Голос Microsoft Павел/Дмитрий (встроенный в Windows движок специальных возможностей SAPI5).

**🔥 Главные преимущества:**
* 🚀 **Легкий запуск в один клик:** Никакой установки Python, библиотек или возни с командной строкой. Просто скачали `.exe`, запустили и играете. 
* 🪶 **Весит копейки:** Сервер занимает всего ~20 МБ. Никаких тяжелых нейросетей на 5 гигабайт, которые нужно скачивать часами.
* 🇷🇺 **Работает в России:** Забудьте про ошибки «недоступно на вашем языке». Всё работает локально и абсолютно бесплатно.

---

## 🚀 Как установить (3 минуты)

1. Перейдите в раздел релизы и скачайте ТТС
2. Распакуйте архив в любую удобную папку.
3. Скопируйте папку `Russian Edge TTS` в вашу папку модов игры (`%APPDATA%\Anywhere RPG\mods\`).
4. Запустите `Russian_TTS_Server.exe` (появится черное окно, сверните его, но не закрывайте).
5. В игре зайдите в `Настройки -> ИИ: речь`, выберите сервис **«Свой»** и укажите URL: `http://localhost:5050/v1`. потом настраивайте вот так

## 📦 Что внутри архива:
1. `Russian_TTS_Server.exe` — сам сервер озвучки (запускается двойным кликом).
2. `Russian Edge TTS` — папка с модом (кладется в папку игры).
3. `README.txt` — подробная инструкция (займет 3 минуты).

> ⚠️ **Внимание:** Серверу нужен интернет для генерации женских голосов, а антивирус может ругаться на `.exe` (это нормально для скомпилированных программ, просто добавьте в исключения).
> ⚠️ С ног до головы создан вайбкодингом
